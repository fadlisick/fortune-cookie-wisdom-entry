Write one original fortune-cookie line for a software developer, 120 characters or fewer. A judge model playing a tired senior engineer picks the line that makes it smile and nod.

The entry writes this line to `entry.txt`:

> You will meet the code you wrote at midnight, and neither of you will remember the other.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (89 characters, no trailing newline). Running it twice produces byte-identical output.
